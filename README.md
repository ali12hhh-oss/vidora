# Vidora

Vidora is an Android video-editing application focused on local media editing, preview, effects, audio, captions, and export.

## Build

Requirements:
- JDK 17
- Android SDK / API 37
- Gradle Wrapper included in the repository

Debug APK:

```bash
./gradlew :app:assembleDebug
```

The repository also contains automated Android build verification under `.github/workflows/`.
